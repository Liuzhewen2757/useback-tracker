# 三个数

每天记一笔：**抖音时长 / 创作时长 / 入睡时间**。

一个单文件网页，不用装任何东西，打开 `index.html` 就能用。这是我"四周用回本计划"第一周的产出——
做出来立刻能用的东西，比学完一门课有用。

## 它能干什么

- 记当天三个数字，随时回来改
- 自动画最近 7 天的抖音/创作柱状对比
- 算 7 天日均、抖音达标天数、创作合计、入睡中位数
- 抖音上限可以自己改（默认 120 分钟）
- 导出 / 导入 JSON 备份

## 数据存在哪（这才是重点）

存在**这个浏览器自己的 localStorage** 里。它不联网、不上传服务器，也不跨设备——
换一台电脑或换一个浏览器，数据就看不见了；清浏览器数据也会一起清掉。

所以：每周点一次「导出备份」，把文件存好。

第二周会把数据搬到真正的后端（Supabase），那时候换设备也能看见，
也就能理解前端和后端的区别到底在哪：**谁在存，谁在读。**

## 怎么打开

双击 `index.html`。想用得方便点，可以在浏览器里把它"添加到主屏幕"，
以后就是一个 App 图标。
